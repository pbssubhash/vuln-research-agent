CREDENTIAL BOUNDARY
===================

  Repository .env (git-ignored, chmod 600)
      GITHUB_TOKEN | NVD_API_KEY | GREYNOISE_API_KEY | VIRUSTOTAL_API_KEY

  ~/.xurl (managed only by the official xurl CLI)
      X OAuth client credentials | access token | refresh token

Neither credential store is included in the exported tarball.
